## Nota de validación estadística

Este documento es el **instrumento**, no el resultado. No contiene respuestas ni valores calculados.
La consistencia interna de las Secciones D, E, F y G (los bloques de escala Likert) se calculará con
**Alfa de Cronbach ≥ 0.75** sobre las respuestas efectivamente recogidas, en el **Anexo 3 — Validación
de instrumentos** (pendiente de aplicar el instrumento a población real — no de un bloqueo de equipo,
`BL-003` ya se cerró con `ADR-011`). Inventar ese valor antes de aplicar la encuesta sería fraude
académico, no un atajo.
